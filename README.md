## Publicação no GitHub Pages
1. Crie um repositório chamado `chaveiro-chagas`.
2. Envie todos os arquivos desta pasta para o repositório.
3. Abra `Settings > Pages`.
4. Em `Source`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve.

## Antes de publicar
Substitua `SEU-USUARIO` em `robots.txt` e `sitemap.xml` pelo seu usuário do GitHub.

## Google Ads e Analytics
O arquivo `js/script.js` já contém pontos preparados para eventos de clique no WhatsApp e na ligação. Após criar suas contas, adicione os códigos oficiais no `<head>` do `index.html`.
